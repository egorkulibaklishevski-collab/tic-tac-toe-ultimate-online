# Tic-Tac-Toe Ultimate Online

## 1. Что нужно
- Аккаунт Supabase: https://supabase.com/
- Проект в Supabase.
- Любой статический хостинг (например, GitHub Pages, Netlify или Vercel).

## 2. Подключить базу и аккаунты
1. Создай проект в Supabase.
2. Открой SQL Editor -> New query.
3. Скопируй весь `supabase_setup.sql`, нажми Run.
4. Открой Project Settings -> API.
5. Скопируй Project URL и anon/public key.
6. Открой `app.js` и замени:
   - `ВСТАВЬ_SUPABASE_URL` на Project URL.
   - `ВСТАВЬ_SUPABASE_ANON_KEY` на anon/public key.
   Никогда не вставляй `service_role` key в браузерный код.

## 3. Запустить на компьютере
Самый простой способ:
1. Распакуй ZIP в отдельную папку.
2. Открой папку.
3. Дважды щёлкни `index.html`.
   Вход/регистрация и бот-интерфейс загрузятся. Для Supabase Auth и Realtime лучше использовать сайт через localhost/HTTPS.

Если установлен Python, открой CMD в папке проекта и выполни:
`python -m http.server 8000`
Затем открой `http://localhost:8000`.

## 4. Опубликовать сайт
1. Создай репозиторий GitHub и загрузи файлы проекта.
2. Подключи репозиторий к Vercel или Netlify.
3. Опубликуй сайт.
4. Открой опубликованный HTTPS-адрес на обоих компьютерах.
5. В Supabase Authentication -> URL Configuration добавь адрес сайта в Site URL и Redirect URLs.

## 5. Важно
- Это стартовый прототип. Реальная регистрация и комнаты работают после подключения Supabase и выполнения SQL.
- Онлайн-комната рассчитана на двух игроков. Код комнаты нужно передать другу.
- Для публикации включи подтверждение email и настрой лимиты регистрации в Supabase.
- Не публикуй service_role key. В браузере допустим только anon/publishable key.
- Лидерборд показывает очки и победы из таблицы профилей. Бейджи TOP 50/Champion пока являются заготовкой интерфейса; для честных сезонных наград нужна отдельная серверная система рангов.
- Локальные достижения игры с ботом хранятся в браузере. Онлайн-матчи сохраняют базовую статистику в Supabase.
- Веб-бот использует эвристическую стратегию на больших полях; Mega Impossible не гарантирует победу.
